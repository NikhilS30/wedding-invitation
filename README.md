# Nikhil & Gauri wedding invitation

2 February 2027, Kisan Bhawan, Sector 35, Chandigarh

Two versions of the same interactive card:

- `nikhil-card/` reads "Nikhil & Gauri"
- `gauri-card/` reads "Gauri weds Nikhil" and has the extra paws slide

Each folder is a complete static page: `index.html`, `img/`, `music.mp3` and
`cover.jpg` (the picture shown when the link is shared).
